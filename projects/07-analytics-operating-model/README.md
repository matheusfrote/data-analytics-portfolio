# Analytics Operating Model & Data Culture

**Strategy case — Grupo RIC**

## Problem

When every department owns its own data interpretation, organizations can end up with inconsistent metrics, duplicated effort and biased reporting.

## Objective

Propose an Analytics function capable of centralizing data, improving consistency and turning reporting into actionable analysis.

## Proposed workflow

1. define objectives and measurement metrics for each business area;
2. collect, centralize, organize and correct data inconsistencies;
3. interpret dashboards and monitoring reports according to business objectives;
4. create analyses and actionable insights.

## Analytical maturity model

The proposal explicitly separated:

- **descriptive** — what happened;
- **diagnostic** — why it happened;
- **predictive** — what may happen;
- **prescriptive** — what to do.

## Proposed capabilities

Engineering · collection · architecture · analysis · coordination

## Business takeaway

Analytics is not only dashboard production. It requires governance, metric ownership, data quality, interpretation and a mechanism that connects insights to decisions.
